# DailyCutReport 0.18.0 — Daily Ledger

- See your balance, intake, burn, and food log together on Today. Foods, Health, and Settings share the new black-and-yellow layout.
- Tap Copy for the selected day or hold it for the seven days ending on that date. **Save weekly JSON** saves the same complete document without relying on clipboard limits. Missing burn and intake are identified separately from recorded zeros. JSON reports contain unencrypted personal data; share them deliberately.
- The first foreground refresh checks yesterday for delayed burn readings. If yesterday is still missing, the app retries on later opens. Manual refresh still rechecks today and the previous 27 days.

Install **arm64** on most modern phones. Use **universal** if you need compatibility with another Android CPU. Existing public-release installations can upgrade in place. The app remains offline and requests no additional permissions.
