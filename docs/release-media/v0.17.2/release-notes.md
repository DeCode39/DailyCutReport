# DailyCutReport 0.17.2

- Tap Copy on Today for one daily JSON report.
- Hold Copy for the seven days ending on the selected date, including that date.
- Weekly JSON includes seven complete, chronologically ordered daily reports, each using its own saved goals, foods, spending, and burn data. Empty days are included; unavailable burn is not guessed.
- The tablet preview supports the same gestures, plus Shift+Enter for a week.

Version code 40. No database or backup migration. Barcode scanning, OCR, planning, and Health Connect synchronization are unchanged. FoodVision is not included.
